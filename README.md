# SLMX Interactive

Website des Indie-Spielestudios SLMX Interactive, ausgeliefert über GitHub Pages.

- `index.html` – Startseite mit REFRAKT und RINGSUM
- `impressum.html` – Impressum und Datenschutz der Website
- `app-ads.txt` – autorisierte Werbeverkäufer für AdMob (muss im Stammverzeichnis der Domain liegen)

Statisches HTML/CSS, kein Build-Schritt. Schrift: Geist (SIL Open Font License, siehe `assets/fonts/GEIST-LICENSE.txt`). Icons: Phosphor (MIT) und Simple Icons (CC0).
